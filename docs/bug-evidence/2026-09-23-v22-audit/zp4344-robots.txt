# robots.txt for the Project Z application host.

# SCOPE / INTENT
# This is a declaration of intent for compliant crawlers only. It is NOT an
# access control and must not be represented as one. Compliant declared
# crawlers honour it; undeclared or spoofed crawlers ignore it. Agentic
# browsers operating inside a logged-in session are out of scope entirely.
#
# Tokenised report and share-link responses are deliberately NOT listed as
# Disallow entries below: a Disallow line would publish the very paths we
# want kept out of indexes. Those responses carry
#   X-Robots-Tag: noindex, nofollow, noarchive
# instead, which is applied at the response layer, not here.
#
# Every token below was verified against current vendor documentation.
# Source URLs and verification dates are recorded in docs/robots-txt.md.
# Verified: 2026-09-23
