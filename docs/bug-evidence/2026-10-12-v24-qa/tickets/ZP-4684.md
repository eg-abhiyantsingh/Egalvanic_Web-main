# ZP-4684 — [Web] Service apply keeps .docx form templates instead of regenerating HTML

Status: Ready for QA · Assignee: Eric Ehlert · Labels: backend

## Description

### What's the problem

During service apply, the backend regenerated form content as HTML even when the service spec already carried a .docx form template - so applying a service replaced the uploaded .docx template with regenerated HTML instead of keeping it. (Console task #129.)

### What's the solution

service_spec_service now keeps the existing .docx form template on apply instead of regenerating HTML for it. This is a cherry-pick promotion of #1480 (daf31ff1) to cicd/dev; single file (app/services/service_spec_service.py), no schema or migration change.

### Fixes

* eg-pz-backend #1483 - Task #129: Service apply keeps .docx form templates instead of regenerating HTML (#1480)

### QA Review

Environment: cicd/dev only (not yet in QA).

* Apply a service to an asset whose service spec has a .docx form template attached; confirm the asset retains the .docx template and does not receive regenerated HTML in its place.
* Negative: for a service spec with no .docx template, confirm apply behaves as before (HTML generated normally).
