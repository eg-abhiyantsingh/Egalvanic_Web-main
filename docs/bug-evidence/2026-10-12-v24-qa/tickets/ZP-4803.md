# ZP-4803 — Tasks #162-164: SLD walks ignore hidden edges, Reset Terminal Positions, combine connections, rotated-node drag + PDF parity

Status: Ready for QA · Assignee: Eric Ehlert · Labels: backend, frontend, ui

## Description

### What's the problem

On the SLD canvas, select up/downstream/lineage, collapse/expand and drag-with-collapsed-parent followed hidden connections, so users moved or selected unrelated parts of the graph by mistake (#162), and there was no way back from hand-dragged terminal positions (#162). A terminal dropped on a rotated node (or a 180-degree dual such as REF1 ATS) landed in the wrong place because the drop stored the drawn side/offset without undoing the render's rotation and dual 'reverse' mirroring (#163). A terminal carrying several connections always split into one virtual terminal per connection, overcrowding the node (#164). The PDF export still mirrored dual-source/target offsets and placed each merged-terminal slot separately, so it disagreed with the canvas.

### What's the solution

goJSActions.buildMaps now skips hidden edges by default for every canvas walk (select, collapse/expand, collapsed-parent drag, straighten, magic layout); electrical tracing lives elsewhere and is unaffected. A node-menu 'Reset Terminal Positions' restores orientation defaults, keeping slots only up to the highest one a connection uses and preserving the combined flag. Terminal drops un-rotate the side (storedTerminalPlacement) and the dual 'reverse' regime is removed (no offset mirror, no Reverse menu item, rotate skips dual nodes). A node-menu 'Combine / Split connections on <terminal>' (terminals with 2+ connections) sets node_manips.terminals\[handle\].merged per scope, collapsing slot pins to slot 0 with no auto-split and no overcrowded flag. The PDF export matches: \_register_node drops the dual-reverse offset mirror, and a merged terminal places slot 0 only with every handle#i ref aliased onto it.

### Fixes

* eg-pz-backend #1536 - SLD PDF export: no dual-reverse offset mirror; merged terminals draw as one dot (tasks #163, #164)
* eg-pz-frontend #1733 - UI SLD: walks ignore hidden edges, Reset Terminal Positions, combine connections, rotated-node drag fix (tasks #162-#164)

### QA Review

* Environment: Dev only (cicd/dev).
* On an SLD with hidden edges, run select up/downstream/lineage and collapse/expand; confirm the walk does not follow hidden connections and unrelated parts are not moved or selected.
* Drag a collapsed parent; confirm hidden connections are not followed.
* Hand-drag some terminals, then use the node menu 'Reset Terminal Positions'; confirm orientation defaults return and the combined flag is preserved.
* Drop a terminal on a rotated node and on a 180-degree dual (e.g. REF1 ATS); confirm it lands where dropped.
* On a terminal with 2+ connections, use 'Combine connections'; confirm it collapses to one dot, then 'Split' restores separate terminals.
* Export the same SLD to PDF; confirm duals are not offset-mirrored and a merged terminal draws as a single dot, matching the canvas.
* Negative: drop onto a combined terminal (stored without slots); confirm no error is thrown.
