# ZP-4580 — Extract from AI on the asset page Schedule and Engineering tabs

Status: Ready for QA · Assignee: Eric Ehlert · Labels: frontend, ui

## Description

### What's the problem

On the asset page, the richer AI extractions could only be started from Edit -> Extract from Photos. The Schedule tab had no AI button at all, and the Engineering tab offered only the plain nameplate read. To run the full schedule / SCCR read ("Attributes + Schedule") or the library designation ("Attributes + Library"), a user first had to enter edit mode, which hid these capabilities from the normal asset-viewing flow.

### What's the solution

A new AiExtractButton surfaces the same two runs as the editor, so a run started on the asset page is the same run as one started in the editor (it re-attaches to a pending run rather than duplicating it): (1) the nameplate read (runNameplateExtraction, fill-blanks-only); (2) the configure job in BulkExtractionJobDialog (enclosure -> schedule specialist; device -> library match), reviewed before Apply, with the page reloading after any write.

* Schedule tab (enclosure classes): a new "Extract from AI" button at the top runs read + schedule (circuits, main + branch devices, SCCR label, panel type).
* Engineering tab: "Extract from Photos" becomes a split button; the dropdown alternative is "Attributes + Library" ("Attributes + Schedule" on bus classes).
* Eligibility gate is identical to the editor's canExtractLibrary: eng-lib plus a library-eligible eqp_lib_type_name, no three-winding transformer; still requires nodes.manage and portal edit.

* On the Engineering tab confirm "Extract from Photos" is now a split button; verify the dropdown alternative is "Attributes + Library" on standard classes and "Attributes + Schedule" on bus classes.
