# ZP-4594 — SLD canvas notes: annotate single-line diagrams with sticky notes (web + API)

Status: Ready for QA · Assignee: Eric Ehlert · Labels: api, backend, frontend, migration, schema, ui

## Description

### What's the problem

There was no way to annotate a single-line diagram — nowhere to leave a note next to the equipment it describes. The legacy sld_comments table already rode the /sld/v2 payload (iOS decodes it as SLDComment) but nothing could write it, and the web SLD editor had no notes affordance at all.

### What's the solution

Backend adds per-view CRUD for canvas notes: migration cnote_a1 extends sld_comments (sld_view_id FK with ON DELETE CASCADE, color, modified_by, text_style JSONB) and new /sld/<id>/canvas-notes + /canvas-notes routes, each tenant-gated via caller_can_reach_sld (reads need slds.view, writes need nodes.manage) with input bounds (coords +/-1e7, size 40-4000, body <=5000 chars, #rrggbb color, text_style ranges). Creates honor a client-minted id and are idempotent for offline replay; deletes are soft tombstones. The web editor renders notes as non-model GoJS Parts (invisible to layout/grouping/connection logic), per view, with click-to-place staging, a markdown subset, Figma-style in-place contenteditable editing, and alignment/color/size controls. Caveat: iOS editing requires the republished OTA viewer bundle and supportsCanvasNotes; older apps show notes read-only.

### QA Review

* Environment: Dev only (cicd/dev, not yet in cicd/qa).
* On the web SLD editor, use + Note to place a sticky note on a named view and on the All Nodes view; confirm placement, markdown rendering (bold/italic/underline/headings/lists), and in-place editing (bold/italic/underline shortcuts, toolbar).
* Set a note's size, horizontal/vertical alignment, and color via the right-click / T menu; refresh and confirm persistence per view.
* Delete a note; confirm it disappears and does not reappear after refresh (soft-delete tombstone).
* Negative: a user with only slds.view (no nodes.manage) cannot create/edit/delete notes; a note request for an SLD outside the caller's company/site returns 404; invalid payloads (bad color, out-of-range size/coords, body >5000) return 400.
* Confirm a note on one SLD cannot be attached to a view belonging to a different SLD.
