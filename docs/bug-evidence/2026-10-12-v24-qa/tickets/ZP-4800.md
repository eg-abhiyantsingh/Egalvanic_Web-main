# ZP-4800 — Task #159: Hide/Show connections on the SLD - hidden edges draw as stubs with jump-to badges

Status: Ready for QA · Assignee: Eric Ehlert · Labels: backend, frontend, ui

## Description

### What's the problem

Heavily redundant electrical systems (ties, alternate feeds) could not be drawn cleanly on the Single Line Diagram: every redundant path added crossed lines until the SLD became a rat's nest, both on screen and in the exported PDF/DXF. There was no way to hide a connection while keeping it as a real electrical link, and nothing carried a per-view hidden state to the embedded mobile SLD viewer, so view-specific hides and pinned elbows were dropped on every viewer refresh.

### What's the solution

Added a Hide/Show Connection action on the edge right-click (web) / long-press (iOS viewer) menu, stored as edge_manips.hidden per scope: a view's own mapping inside a view, edges.edge_manips in All Nodes, so an All Nodes hide never bleeds into a view. A hidden edge now draws a short solid stub out of each terminal ending in a '<other end> ->' badge that pans to and selects the equipment at the far end; selecting the edge shows the full route as a dashed adornment. A 'Show hidden connections' toolbar/overflow toggle ghosts hidden edges for auditing. Highlight / AF-status / zoom-simplify restyles recolor the stubs instead of repainting the route, and layout ops (straighten, magic layout) ignore hidden edges while tracing and selection still treat them as real connections. The PDF/DXF export prints each hidden edge as a short stub ending in an off-page-connector 'TO <other end>' tag, scoped the same way as the canvas. The iOS SLD viewer now sends has_view_specific_points plus only the view's own edge_manips so view elbows/hides survive every refresh (display only; views stay read-only on mobile). No backend schema change - edge_manips is existing JSONB. Caveat: the mobile SLD viewer needs an OTA viewer publish per environment to pick up the stub/badge rendering.

* On a redundant SLD, right-click an edge (web) and choose Hide Connection; confirm it collapses to a short stub at each terminal with a '<other end> ->' badge and the full route disappears from the canvas.
* Click a badge; confirm the canvas pans to and selects the equipment at the other end.
* Select the hidden edge; confirm the full route shows as a dashed adornment.
* Toggle 'Show hidden connections'; confirm hidden edges render as ghosted dashed routes, then hide again.
* Hide in a view vs in All Nodes; confirm an All Nodes hide does not appear inside a view and vice versa (scope isolation).
* Run straighten / magic layout; confirm hidden edges are ignored but tracing and selection still include them.
* Export the SLD to PDF/DXF; confirm each hidden edge prints as a short stub ending in a 'TO <other end>' tag, scoped per view.
* In the iOS SLD viewer (after OTA publish), open a view with pinned elbows and hidden edges and trigger a data refresh; confirm elbows/hides persist and an All Nodes hide does not leak into the view.
* Negative: un-hide a hidden fixed-edge chain; confirm elbows are restored and it does not expand into a chain.
