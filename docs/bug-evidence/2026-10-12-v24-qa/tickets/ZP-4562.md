# ZP-4562 — Hide "Fill from Photos" on work orders (task #46)

Status: Ready for QA · Assignee: Eric Ehlert · Labels: frontend, ui

## Description

### What's the problem

The "Fill from Photos" form-fill feature gave poor results — the latest QA jobs filled 0 of 9 targets — so the decision was to take it away from users.

### What's the solution

SessionDetail.jsx adds FILL_FROM_PHOTOS_ENABLED = false, which turns off canFillForms and hides both entry points: the work-order menu (EG Forms → Fill from Photos) and the Forms tab action. The dialog (FillFormsFromPhotosDialog), formFillJobService, the backend /form-fill/jobs routes, the pipeline runner and the Step Function are all left in place; setting the constant back to true restores the feature. No behaviour change beyond hiding the UI.

### Fixes

* eg-pz-frontend #1607 — UI Hide "Fill from Photos" on work orders

### QA Review

Environment: dev only (not yet in QA).

* Open a work order and the EG Forms menu: confirm "Fill from Photos" no longer appears.
* Open the Forms tab: confirm the Fill from Photos action is gone.
* Confirm the rest of the EG Forms menu and Forms tab still work normally.
* Negative: no console error from the removed menu path; other work-order actions are unaffected.
