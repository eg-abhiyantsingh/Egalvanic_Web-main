# ZP-4799 — UI SLD: placeholder dot per orientation terminal on unwired nodes

Status: Ready for QA · Assignee: Eric Ehlert · Labels: frontend, ui

## Description

### What's the problem

Since virtual terminals shipped (#1161), the GoJS SLD editor only draws ports that something is actually wired to, and a node only carries node_terminals rows for terminals it has already used. A brand-new or still-unconnected node therefore rendered with no terminal dots at all, giving the user no visual hint of the node's orientation or of where a connection could be made.

### What's the solution

GoJSGraphEditor.jsx (mapNodesToGoJS / ensureTerminalPort) now fills any missing terminals from the class blueprint (node_orientation.orientation_terminals) as unsaved placeholders (mock: true), so each orientation terminal shows its default dot. Empty extra slots and coincident unused LINE/LOAD twins stay hidden, and a wired terminal at a spot hides the unwired ones there. On connect, ensureTerminalPort mints a real terminal and replaces the placeholder. Simplified nodes and groups are unchanged.

Caveat: the change lives under src/sld, so it needs an OTA republish per environment via scripts/publish-sld-viewer.sh <env> before it is visible.

### Fixes

* eg-pz-frontend #1729 — UI SLD: show one placeholder dot per orientation terminal on unwired nodes

### QA Review

Environment: dev only (not yet in QA). Requires the SLD viewer OTA republish for the target env (scripts/publish-sld-viewer.sh <env>) before testing.

* On the GoJS SLD editor, add a new node (or open an unconnected one) and confirm each orientation terminal now shows a placeholder dot that reflects the node's orientation.
* Confirm a wired terminal at a given spot hides the unwired placeholder dots there (no duplicate or overlapping dots).
* Confirm coincident unused LINE/LOAD twins and empty extra slots remain hidden.
* Make a connection onto a placeholder terminal and confirm it is replaced by a real, saved terminal (ensureTerminalPort).
* Confirm simplified nodes and groups render exactly as before.
* Negative case: reload the diagram and confirm the placeholder dots (mock) were never persisted as node_terminals rows — they should reappear as placeholders, not as saved terminals.
