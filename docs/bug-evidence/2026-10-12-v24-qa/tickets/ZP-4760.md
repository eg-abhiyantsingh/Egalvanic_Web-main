# ZP-4760 — SKM export: diagram layout attributes, node-bus study flags, and unsuffixed arc-flash labels

Status: Ready for QA · Assignee: Eric Ehlert · Labels: backend

## Description

### What's the problem

When a single-line diagram was exported to SKM (PTW), the generated XML dropped information the desktop tool relies on, so the import needed manual cleanup every time. Component positions were not carried into the export, so the imported diagram had no layout and had to be re-arranged by hand. Node buses were not reliably included in studies, so they could be left unsized or excluded. And arc-flash label numbers taken from a node's location were written with an unwanted suffix instead of the verbatim location label.

### What's the solution

The SKM exporter now carries the missing data into the XML:

* Stamps each component tag with diagram layout attributes eg_x / eg_y (plus eg_width on group types), computed as absolute coordinates relative to the parent, so SKM renders the diagram in the same arrangement as the app. A node with no stored position falls back rather than emitting a wrong position.
* Pins the PTW study checkboxes on every node bus (Do Not Size on, all Exclude flags off) so node buses are always sized and never dropped from a study.
* Writes AF_LabelNumber from a bus's location verbatim (unsuffixed).

This shipped first as prod hotfix #1524 (Task #153) and was cherry-picked down the release cascade (stage, QA) to cicd/dev as #1527. Backend-only; there is no frontend change.

### Fixes

### QA Review

Environment: dev + QA (also cascaded to stage and prod via hotfix #1524).

* Export an SLD with a multi-level hierarchy (groups + child nodes + node buses) to SKM and open it in PTW. Confirm components land at the same relative positions as in the app (eg_x / eg_y, and eg_width on groups).
* On an imported node bus, confirm Do Not Size is checked and every Exclude flag is unchecked, so the bus is sized and included in studies.
* Confirm AF label numbers derived from a bus's location are written without a suffix.
* Negative case: export a node that has no stored diagram position and confirm no bogus layout attributes are emitted (it falls back rather than writing a wrong position).
