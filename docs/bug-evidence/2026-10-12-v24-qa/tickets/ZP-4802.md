# ZP-4802 — Task #140: Hide opportunities - mint one per quote; tenant-gate opportunity soft-delete

Status: Ready for QA · Assignee: Eric Ehlert · Labels: api, backend, frontend, ui

## Description

### What's the problem

Creating a quote required picking or creating an opportunity, and the picker filled up with stale entries; the team no longer wants the opportunity concept in the quote flow (task #140). Separately, DELETE /opportunity/<id>/soft-delete had no tenant check - any opportunities.manage user could soft-delete another company's opportunity by id, and deleting one could orphan its quotes.

### What's the solution

Opportunities become a hidden backend detail. A helper quote_creation_guards.mint_opportunity_for_quote(title, sld_id, owner) creates a hidden one-per-quote opportunity (named after the quote, on its site and account, status qualifying), used when no opportunity_id is sent by POST /plans, POST /plans/from-issues (opportunity_id no longer required), POST /plans/from-walk and POST /quote/create-standard (now accepts sld_id + title, tenant-checked via require_payload_tenant); legacy EMP creation already minted one from a name. POST /plans now 404s a site the caller cannot reach (caller_can_reach_sld; malformed id -> 404) since it writes an opportunity onto that site. Soft-delete now 404s unless the caller can reach the opportunity's site (or its account's company for site-less legacy rows) and 409s while live legacy quotes or v2 plans remain. The UI removes the opportunity picker, info tooltip, subtitle and New Opportunity dialog from Create Quote and Add-to-Quote-from-issues, removes the Opportunity column from the Quotes grid, unroutes /opportunities/:id (redirects to the Quotes list), and re-enables deleting legacy EMPs that were linked to an opportunity. Explicit opportunity_id callers (OpportunityDetail Add Quote, API) are unchanged. Caveat: deploy the backend first - without it, standard quotes and quotes-from-issues refuse a missing opportunity_id.

### Fixes

* eg-pz-backend #1535 - Task #140: Hide opportunities - mint one per quote; tenant-gate opportunity soft-delete
* eg-pz-frontend #1732 - UI Task #140: Hide opportunities from quote creation and lists

### QA Review

* Environment: Dev only (cicd/dev); deploy the backend before the frontend.
* Create a standard quote from the Quotes page; confirm there is no opportunity picker, tooltip, subtitle or New Opportunity dialog, and the quote is created (a hidden opportunity is minted on the site/account behind the scenes).
* Add to quote from issues; confirm no picker and the quote is created without an opportunity_id.
* Quotes grid: confirm no Opportunity column and the delete prompt no longer names an opportunity.
* Navigate to /opportunities/<id>; confirm it redirects to the Quotes list.
* Delete a legacy EMP that was linked to an opportunity; confirm it is deletable again.
* Negative (tenant): call DELETE /opportunity/<id>/soft-delete for another company's opportunity id; confirm 404.
* Negative (orphan guard): soft-delete an opportunity that still has live legacy quotes or v2 plans; confirm 409.
* Negative (site reach): POST /plans with a site the caller cannot reach or a malformed sld_id; confirm 404.
