# ZP-4573 — Photo Walkthrough V2 (task #70): per-shot photo classifier endpoint + live-camera walkthrough with AI labeling - backend + iOS

Status: Ready for QA · Assignee: Kush · Labels: api, backend, schema

## Description

### What's the problem

Photo Walkthrough v1 pushed and dismissed the camera for every single photo, walking each asset through capture -> classify -> sub-component prompt -> What's Next. Photographing a room full of equipment took dozens of screens, and nothing was read from the photos. No endpoint could label a shot (photo category and asset class) at the moment of capture, before the asset exists: the existing extract-temp-nameplate-data needs the class up front and returns no category.

### What's the solution

Photo Walkthrough V2 (task #70), built beside v1 and left off by default.

* Backend adds POST /extraction/walkthrough/classify-photo: given one staged temp-bucket photo it returns photo_category (profile / nameplate / panel schedule / arc flash sticker / other), the best-matching company class (globals dropped, below 65% confidence dropped), a confidence, and the asset_label read off an ID tag. Tenant-safe: only temp-bucket URLs are fetched, a caller-supplied node_class_id is honoured only when it belongs to the caller's company (404 otherwise), and a model refusal returns 422. Runs on the workhorse model.
* iOS adds a single live-camera session (Views/PhotoWalkthrough/V2): shutter lands on the current asset, Next asset / Next sub, a Lineside/Loadside sub-component mode, tray cards and an Assets sheet with a per-asset editor. Every shot is classified online, then each photo of a classed asset is read by extract-temp-nameplate-data (fill-blank only, manual edits pinned). A lineside Circuit Breaker / Fuse under a bus fills the parent's blank Mains Type. Offline it saves photos as Profile with class quick-picks and no AI.

Caveat: rollout is LaunchDarkly only (feature-photo-walkthrough-v2), default off, no company_features fallback -- currently on for demo.dev only. v1 is unchanged at every entry point.
