# ZP-4762 — SKM export: exclude node buses from every PTW study (Exclude flags checked)

Status: Ready for QA · Assignee: Eric Ehlert · Labels: backend

## Description

### What's the problem

In the SKM/PTW model exported from the platform, node buses were being left enabled in every power-system study. A node bus is a pure connection point between equipment, not real equipment itself, so it must not participate in Load Flow, Short Circuit, Equipment Evaluation, Arc Flash (bus and line-side), or Coordination studies. The node-bus study-flag work from task #153 (shipped as ZP-4760) pinned every node bus to "Do Not Size" ON but deliberately left all four "Exclude ..." flags OFF, on the assumption that a node bus should never be excluded from a study. That was backwards: with the Exclude flags off, opening the exported model in PTW pulls node buses into those study calculations and skews the results.

### What's the solution

Hotfix #1528 (task #155) flips every node-bus Exclude flag to checked in the SKM XML output. On each node bus the export now writes DE_Excluded (Exclude Load Flow/SC/Equip Eval), AF_Exclude_Bus (Exclude Arc Flash Bus Calc), AF_Exclude_LineSide (Exclude Arc Flash Line Side Calc) and CoorEval_Excluded (Exclude Coor Eval) all = True, while "Do Not Size" stays on. These study flags are forced on every node bus, so a stray core attribute on the source node cannot override them. This is a correction to the node-bus behavior introduced in ZP-4760 and touches only the export output generation. It shipped first as a cicd/prod hotfix (#1528) and was cherry-picked up to cicd/dev.

### Fixes

* eg-pz-backend #1531 — SKM export: node-bus Exclude flags checked, not cleared (#1528)

### QA Review

Environment: dev + QA (merged to cicd/dev as #1531 and cascaded through cicd/qa via #1530; also on stage/prod).

* Export an SKM/PTW model from a project that contains at least one node bus (a connection point between equipment, not a real panel/switchboard bus).
* Open the exported XML (or the model in PTW) and locate a node bus. Confirm its study checkboxes read: "Do Not Size" = on, and all four Exclude flags checked — DE_Excluded, AF_Exclude_Bus, AF_Exclude_LineSide, CoorEval_Excluded all = True.
* Negative case: confirm a normal (non-node) equipment bus is unaffected — its Exclude flags are not force-checked by this change.
* Regression: confirm the node-bus diagram layout attributes (eg_x/eg_y/eg_width) and the "Do Not Size" pin from ZP-4760 still export as before; only the Exclude flag values changed (False → True).
