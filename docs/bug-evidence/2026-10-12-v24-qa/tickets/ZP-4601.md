# ZP-4601 — Task #87: SLD canvas notes show who wrote them (author byline, web + API)

Status: Ready for QA · Assignee: Eric Ehlert · Labels: api, backend, frontend, ui

## Description

### What's the problem

Canvas notes on the single-line diagram gave no hint of who left them. The backend resolved a note's author_name to users.username (the Cognito handle) rather than a readable name, and the web canvas had no byline element, so a note could not be attributed to a person.

### What's the solution

Backend SLDComment.author_names() now resolves 'First Last', falling back to email, then 'Unknown', in a single query, and both the canvas-note routes and the two /sld/v2 comment builders use it. The web GoJS editor draws a small grey italic byline (name, or email) under each note's bottom-right corner, outside the note body so it never consumes text space and a wide byline cannot shift the note; web-created notes pick up the name from the create response. Display-only; needs a dev OTA republish of the SLD viewer bundle (src/sld) after merge.

### Fixes

* eg-pz-backend #1448 - Task #87: canvas note author_name = full name, else email
* eg-pz-frontend #1637 - UI Task #87: author byline on SLD canvas notes

### QA Review

* Environment: dev only (not yet in QA).
