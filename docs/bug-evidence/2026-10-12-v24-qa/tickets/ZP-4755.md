# ZP-4755 — Planned Work v2: booked work -> planned work orders, planning pipeline, scheduling notices & field-team release (Task #139)

Status: Ready for QA · Assignee: Eric Ehlert · Labels: api, backend, frontend, migration, schema, ui

## Description

### What's the problem

Accepted quotes and EMPs couldn't be turned into Planned Work v2 work orders - there was no path from booked work to planned WOs. The Planned Work list showed no status pipeline or next-step data, so users couldn't see where each planned job stood. Scheduling notices had no per-recipient 'can confirm' choice, no change reason, no reminder, and no pre-send preview. The create stepper and schedule editor didn't match the new designs, and Release went out without checking who was actually going to the field. Separately, MainDataGrid ignored each grid's rowHeight (rows were forced to 40px).

### What's the solution

Backend (feature-planned-work-v2): create planned WOs from plans (POST /plans/planned-workorders/create) and release-as-planned, with change orders blocked and reopen/delete guarded while planned WOs exist; a Planned Work list with a stage filter, pipeline counts and per-row stage / waiting_on / confirmed_by / issue; notices gain a nullable can_confirm (migration noticecc_a1), a change reason stored on the revision and quoted in the change email, a remind endpoint, and a sample preview that renders for real then rolls back; release-team endpoints (GET release-team; release takes user_ids / add_crew_ids). Dashboards: Needs Attention endpoints removed, work-orders/by-service and workorders/v2 closed_since added.

Frontend: a booked-work banner + 'Plan Booked Work' dialog that creates planned WOs and deep-links the quote/EMP to the WO pricing tab; a Planned Work status pipeline (Unscheduled / Tentative / Partially confirmed / Confirmed) wired to filter, sidebar sub-items, next-step buttons and status chips; a rebuilt Ops Overview (deadline model) and a new Planning Board page; a flag-gated create stepper (site/name/work-window, service cards, assignment list, timeline schedule grid, notices with Can confirm / Notify only recipients, sample email preview); a schedule editor with a required change reason and a Send reminder action; a Release dialog with the field team (crews, subcontractors, individuals). MainDataGrid now honours gridProps.rowHeight (Work Orders 58px, Logos & Media 52px). Caveat: Needs Attention is removed from the Ops and Sales dashboards.
