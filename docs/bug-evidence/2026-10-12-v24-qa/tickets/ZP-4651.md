# ZP-4651 — Photo Walkthrough v2: classify-photo offers OCP classes for top-level assets (Task #103)

Status: Ready for QA · Assignee: Eric Ehlert · Labels: api, backend

## Description

### What's the problem

In the photo walkthrough, the classify-photo endpoint filtered candidate classes by ocp == sub_component. A top-level (whole-equipment) photo therefore never saw any OCP classes, so a standalone breaker or fused disconnect photographed on its own could never be auto-classified as the OCP device it actually is.

### What's the solution

Top-level shots now offer every non-bus company class, while sub-component shots stay OCP-only as before. The classification prompt was updated to classify the whole piece of equipment: a panel full of breakers resolves to a panel class, and a lone breaker in its own enclosure resolves to that device's class. The paired iOS PR (#694) fixes the matching manual picker on the client.

* eg-pz-backend #1475 - Photo Walkthrough v2: offer OCP classes for top-level assets
