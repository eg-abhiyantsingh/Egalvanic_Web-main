# ZP-4581 — UI: Building → Floor → Room filter on Arc Flash Readiness (Task #78 / TKT-1428)

Status: Ready for QA · Assignee: Eric Ehlert · Labels: frontend, ui

## Description

### What's the problem

On multi-building sites the Arc Flash Readiness tab aggregated every building together — the overview gauges, class cards, Asset Details, Source/Target and Connection Details all mixed assets from the whole site. A field crew working one building (or one room) had no way to narrow the view to just that location's readiness. P&H raised this as TKT-1428.

### What's the solution

Added a single Building → Floor → Room location filter that applies across the whole Arc Flash Readiness page through a new utils/locationFilter rule, covering the Overview gauges and class cards, Asset Details, Source/Target and Connection Details.

* Progressive header dropdowns: Floor appears after a building is chosen, Room after a floor; changing a higher level clears the levels below it, and switching sites drops levels that no longer apply.
* A "No …" option surfaces unlocated assets.
* The Asset Details class picker only offers classes present in the selected location.
* Connection Details now retains its node map (previously discarded) so connections can be filtered — a connection counts when either end sits in the location, while the source-side check still walks the whole site.
* Adds en/fr strings and spacing before the Engineering Mode toggle.

Frontend-only change: client-side filtering over data already loaded for the page; no new API calls.

* Select a building in the header; confirm the Floor dropdown appears and the gauges, class cards and Asset Details now reflect only that building.
* Select a floor, then a room; confirm each level further narrows the view.
* Change the building and confirm the floor/room selections below it are cleared.
* Confirm the Asset Details class picker lists only classes present in the chosen location.
* Confirm Connection Details filters correctly — a connection appears when either endpoint is in the selected location.
* Choose the "No location" option and confirm unlocated assets are shown.
* Switch to a different site and confirm location levels that no longer exist are dropped.
* Switch the app language to French and confirm the filter labels are translated.
