# ZP-4720 — Let Cable and Busway be added to services and PM plans

Status: Ready for QA · Assignee: Eric Ehlert · Labels: frontend, ui

## Description

### What's the problem

Cable and Busway are real pieces of equipment - a busway needs IR scans and torque checks, a cable needs insulation testing - but neither could be added to a service's covered classes or to a PM plan. Both the Add-to-PM-plan dialog (AddPmPlanDialog) and the Add-class-to-service dialog (ServiceWorkOverview -> AddClassDialog) filtered out every pseudo-edge class, lumping Cable and Busway in with the node bus, which is a pure topology construct with nothing to maintain. The result was that techs had no way to schedule or record maintenance for cable and busway runs.

### What's the solution

Removed the is_pseudo_edge exclusion from both pickable-class filters so Cable and Busway now appear in the Add-to-PM-plan picker and the Add-class-to-service picker. Only the node bus (is_node_bus) stays excluded, since it genuinely has no maintenance to schedule. The lists still drop deleted classes and remain alphabetically sorted. Shipped as a prod hotfix (#1686) and cherry-picked up the chain to stag, qa and dev - the feature is already live in prod.

### QA Review

Environment: Dev + QA (also already shipped to prod).

* Open a service's Add-class dialog and confirm Cable and Busway now appear in the class list, alphabetically placed, alongside the standard equipment classes.
* Add Cable to a service and add Busway to a service; confirm each creates its procedure/record section (busway -> IR + torque, cable -> insulation testing).
* Open Add-PM-plan and confirm Cable and Busway are selectable there too, and a PM plan can be created for each.
* Negative case: confirm the node bus is still NOT pickable in either dialog, and deleted classes still do not appear.
