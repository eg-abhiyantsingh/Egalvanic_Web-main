# ZP-4614 — Joining a work order no longer auto-registers unchosen services (Task #96)

Status: Ready for QA · Assignee: Eric Ehlert · Labels: api, backend

## Description

### What's the problem

Every node-session link - web asset picker, create drawer, mobile map-in, and relink - ran register_added_assets, which evaluated every service on the work order against the new asset and registered whatever matched. Assets picked up services nobody chose (on dev, NPNL joined WO5678 and got Clean/Tighten/Torque and Torque Verification even though the user had unticked both in the mobile post-create prompt). add-assets with no service also silently fell back to the legacy work type.

### What's the solution

Decision (Eric): no background decisions. Services come only from the work order's creation spec (materializer, unchanged) and explicit by-service adds (/add-assets with a service, /method-lines, Manage Services, the mobile prompt). register_added_assets and all four hook calls in MappingController (create, bulk create, relink x2) were removed; unlink still removes the asset's method lines. add_assets_to_work_order with service_id=None is now membership-only, with no fallback to session.work_type_id. Behavior change: adding or relinking an asset via the web asset picker or create drawer no longer gives it any services - use the by-service add paths. The iOS half ships in iOS #682. No migration.

### Fixes

* eg-pz-backend #1457 - Task #96: joining a work order registers no services

### QA Review

Environment: dev only.

* On dev, add an asset to a work order via the web asset picker and via the create drawer; confirm no services are registered on it (no asset_add method lines).
* Relink an asset to a work order; confirm it gains no services automatically.
* Call /add-assets with no service_id; confirm the asset is added as membership-only with no fallback to the session work type.
* Positive path: add a service explicitly via /add-assets with a service, Manage Services, or /method-lines; confirm it is registered. Unlink an asset and confirm its method lines are removed.
