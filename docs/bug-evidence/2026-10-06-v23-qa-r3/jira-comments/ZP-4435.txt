*What happened*
* Badge: nodes with photos show a camera badge with the count (1, 2). "child 1" (0 photos) has no badge; hovering it opens nothing and sends no request. Panelboard groups with photos (Panelboard 1 has 3) show no badge and open nothing.
* Hover: the popover "Photos for <node>" opens beside the node — right of it, flipped to the left when the node is at the right edge, never over it — with the class and location line, PHOTOS n and the thumbnails. The first hover makes two requests (the photo list, then the signed addresses); hovering the same node again makes none. Loading the diagram makes no photo request.
* Clicking a thumbnail opens the full-size viewer on top; the canvas stays and its pan and zoom are unchanged after Escape. Twice in 7 tries a real click on the thumbnail only focused it and opened nothing; it did not happen again while I was recording the events, so I could not pin it down.
* *Keyboard — fails:* with the node selected, Enter tries to edit the node (toast "Editing is locked"), Space does nothing, and Tab leaves the canvas (nodes are not in the tab order). The key handler looks for a key named "Space", but the diagram reports the space bar as " ", so the keyboard path can never open the popover.
* Lock Graph off: no badges and no popover; on again: both are back.
* Failure states (simulated): one failed signed address → one silent re-request and the thumbnail loads, no broken image. An address that fails every time → the tile shows "Unavailable" with Retry after exactly one re-request, the popover stays; Retry loads the photo.
* "Open asset" opens the asset page in a new tab.
