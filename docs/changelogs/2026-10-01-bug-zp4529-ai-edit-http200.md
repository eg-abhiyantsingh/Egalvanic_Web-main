## Why the message says "HTTP 200"
From the QA build (`ReportingConfigEditor` chunk): after `POST /reporting/configs/<id>/ai-edit` the editor throws when
`!response.ok || !body.success`; the error text is `body.error || body.message`, and when both are empty it falls back to
`Could not start the AI edit (HTTP ${status})`. So the server answered 200 without `success: true` and without an error
message. On QA (30 Sep, build index-DXSz_B6n.js) the same action on an SLD config answered 200 with success and the job ran
(ZP-4398). This is in the ticket's "For the developer" line.
