### The thing worth carrying forward

**The copy button is not one click.** It opens *"Copy &lt;section&gt; to N other assets?"* with
**Only fill blanks** (the default — "existing answers are kept") and **Overwrite everything**. My first
click produced no toast and no change and looked *exactly* like the bug in the ticket — the dialog was
waiting. Worse for triage: under the default option a card that already holds a differing answer is
left alone **by design**, which is indistinguishable on screen from "the copy did nothing". Anyone
retesting, or triaging a repeat report, has to establish which option was used first. All measurements
used *Overwrite everything*.

## ZP-3887 (MCP connector per-company entitlement) — **NOT VERIFIABLE FROM HERE**

`GET /auth/oauth-config/<company_code>` is **not exposed on the customer web host**. Six path variants
× two tenant hosts × six company codes all returned the SPA catch-all HTML. Control: `/api/auth/me` on
the same host returns proper JSON `401`, so `/api/auth/*` does reach the backend — this route does not
live here. Seven of eight review items are therefore unreachable, and the eighth (branch markers) needs
the backend repo, which the GitHub connector could not reach this session.

Weak positive recorded: nothing I could construct from the public host returned Cognito pool
coordinates for any tenant.

**To unblock:** (1) the base URL the MCP server actually calls; (2) LaunchDarkly access to target and
untarget `feature-mcp` on QA — the connector in this session exposes only an authenticate step, and
flipping a customer entitlement flag should be a sanctioned action anyway; (3) read access to
eg-pz-backend for the marker and `_EXEMPT_VIEWS` items.

## Method notes

- **JS-dispatched clicks do not work on this app's MUI grids** — rows need real pointer events. Several
  navigation attempts failed silently until switched to Playwright locator clicks. A right-anchored
  **MUI Drawer** also intercepts pointer events until dismissed with Escape.
- **The EG form renderer opens as a right-anchored drawer, not a dialog** —
  `.MuiDrawer-anchorRight.MuiDrawer-modal .MuiDrawer-paper`. A `[role="dialog"]` selector misses it
  entirely, which cost several probes.
- **Identify participant cards by their own copy button**, not by walking up from a heading: the
  heading walk-up lands on shared ancestors and reports all three cards as identical. Anchor on the
  per-card copy button and take the smallest ancestor containing exactly one of them.
- Button labels change with state — `Read pages` → `Read 1 page`, `Apply` → `Apply 2 Changes` — so
  exact-match locators break mid-flow.
