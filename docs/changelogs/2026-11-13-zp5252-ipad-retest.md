## iPad automation traps found
- After sign-in a **two-factor setup screen** can block all taps and typing while the page source still shows Select Site. Relaunching the app (terminate + activate) showed it; then "Set up later".
- The notification permission prompt was not reachable through the Appium alert API (404 no such alert). A coordinate tap on "Don't Allow" (336,646) worked.
- PHPicker photos have no accessibility labels: tap the grid by coordinates. Then "Use Photo" on Review Photo is also coordinate-only (609,1130).
- iPad sheets: `hideKeyboard` can dismiss a form sheet. A `placeholderValue == "Enter asset name"` predicate also matches the **parent** asset's name field behind the sheet. Pick the child field by its rect (y≈402, x≈160).
- Page source on a big asset page with a sheet open took ~25 s per call.
